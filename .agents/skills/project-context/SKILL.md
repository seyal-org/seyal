# Project context

Search narrowly with `rg` / `git grep` (or GitHub code search when working remotely) using Issue terms, then read the relevant accepted architecture, ADR, spec, milestone, source and test files. `AGENTS.md` defines source precedence. Never assume stale cached summaries or search snippets are authority. If a path or link is stale, inspect the primary source and report ambiguity instead of guessing. There is no framework preflight or context-index dependency.
