## Flow, Raw, and full-screen programs

A Pane starts in **Raw**: the live terminal grid in that Pane. **Use Flow** in the command palette (when shell integration allows) shows command Blocks and the composer instead. **Use Raw Terminal** returns to the grid. A full-screen program, such as an editor, takes over that same terminal (TUI). Leaving the program returns to Raw or Flow, whichever was the resting choice, without opening a second terminal.

## Documentation rule

A feature may appear here as **available** only when the implementation is merged, tested, and demonstrable. Planned capabilities must be labelled clearly as planned or under development.
