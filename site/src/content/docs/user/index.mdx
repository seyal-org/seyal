## Raw terminal and full-screen programs

A Pane opens to the **Raw** terminal: a conventional terminal grid with direct keyboard input. Blocks and the Flow composer are suspended for v1, and there is no user-facing presentation switch. A full-screen program, such as an editor, takes over that same terminal (TUI). Leaving the program returns to Raw without opening a second terminal. Raw terminal acceptance is still under development; see [What is available now?](./current-status.md).

## Documentation rule

A feature may appear here as **available** only when the implementation is merged, tested, and demonstrable. Planned capabilities must be labelled clearly as planned or under development.
