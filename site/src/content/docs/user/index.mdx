## Flow, Raw, and full-screen programs

A Pane starts in **Flow**: command Blocks and the composer. **Use Raw Terminal** in the command palette replaces that with the live terminal in the same Pane. A shell that cannot keep a trusted command prompt does the same. A full-screen program, such as an editor, takes that same terminal. Leaving the program returns to Flow or Raw, whichever was in use, without opening a second terminal. **Return to Flow** in the command palette leaves an explicit Raw choice and shows Blocks again when the prompt is trusted.

## Documentation rule

A feature may appear here as **available** only when the implementation is merged, tested, and demonstrable. Planned capabilities must be labelled clearly as planned or under development.
